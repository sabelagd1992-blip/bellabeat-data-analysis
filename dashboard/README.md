# Bellabeat Dashboard

This folder contains the dashboard created for the Bellabeat Google Data Analytics Capstone Case Study.

The dashboard summarizes the main findings related to:

- Daily activity and steps
- Sedentary behavior
- Sleep patterns
- Activity by day of the week
- Key insights
- Marketing recommendations for the Bellabeat App

The dashboard was created using Google Sheets.
### Dashboard Files

The dashboard documentation is available in the [`dashboard`](./dashboard) folder.
